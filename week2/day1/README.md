# Prompt Engineering - Issue Classification

## Overview

Today I learned how to design structured prompts using different prompt engineering components and use an LLM to classify customer complaints.

## Prompt Components

- **Role** - Defines how the LLM should behave.
- **Task** - Defines what the LLM needs to do.
- **Constraints** - Defines the rules the response must follow.
- **Output Format** - Defines the expected response format.
- **Example** - Shows the model an example of the expected behavior.
- **Fallback** - Defines what to return when the issue does not match the given categories.

## Categories

The model classifies complaints into:

- Billing
- Technical
- Return
- Other

## Key Learning

I learned how structured prompts can guide an LLM to produce more consistent and controlled outputs.
