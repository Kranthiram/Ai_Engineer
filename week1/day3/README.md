# Day 3 - Token Usage

## Topics Learned

- Prompt tokens
- Completion tokens
- Total tokens
- `max_tokens`
- `finish_reason`

## Key Concepts

- `prompt_tokens` → Tokens used for the input.
- `completion_tokens` → Tokens generated by the model.
- `total_tokens` → Input + output tokens.
- `max_tokens` → Maximum output tokens allowed.
- `finish_reason` → Explains why the model stopped generating.

### Finish Reasons

- `stop` → Model completed the response normally.
- `length` → Maximum output-token limit was reached.
